# Kin recognition

Status: idea.

## What it does

Lets a creature tell its own species from others that show the same features,
as one more feature with pulls of its own in the scoring brain.

## Why it is interesting

Roadmap entry 11 makes the brain a sum over features that components show, and
same species is not a component, so it is left out. While rabbits are the only
animal carrying `Meat`, a rabbit's pull toward `Meat` is its pull toward other
rabbits. A second meat-carrying herbivore, such as a deer, would get the same
reaction until something tells them apart.

## What it would touch

The feature catalog and every species using the scoring brain, which gain the
feature's pull genes at 0. Either a component that shows a species marker, or a
feature the sense adds when an entity's species matches the viewer's.

## Open questions

Whether kin is a component, which keeps the brain reading only what components
show, or a fact the sense derives, which is simpler and is the one feature no
component produces.
